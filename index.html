CSV format & safe experiment guide

Use start,end,watts,phase. Each row is an interval-average power reading in watts, with minute-aligned ISO timestamps and an explicit fixed timezone offset. Phase is before or after; provide exactly one night for each. Maximum file size: 1 MB. Keep timezone offset fixed; split daylight-saving transitions first.

Example: 2026-10-20T22:00:00+09:00,2026-10-20T23:00:00+09:00,120,before

Only common clock-time coverage is compared. Missing data are excluded. Unequal conditions can explain the difference. The tool does not establish causation, classify all baseline consumption as waste, or determine whether equipment is safe to disconnect. Leave refrigeration, medical, safety and essential equipment alone.
